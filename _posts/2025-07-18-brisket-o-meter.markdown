### The "Problem"

I like barbecueing (that is barbecue, not grill), and I've got a nice Kamado
Joe. The thing with barbecueing is that you can't just cook a steak and call it
a day. You want to act as if you're a professional chef who'se been doing this
for all his life, and you want to be "that guy".  It's also a nice non-computer
thing I can spend some time doing, and learning about. So there's that.

So, the first thing I wanted to cook was a brisket. I never had it, but it looks
so delicious. The problem is this thing has to be cooked for upwards of 8 hours
at a stable temperature. If you cook it too fast, it will be dry and tough, if
you cook it too slow it will be dry and.. tough.

So we want to make sure our barbecue is running at a stable temperature for
hours on end. You can buy things like a BBQ Guru to help you with this, but
theyre very expensive. I just bought a Kamado Joe, so I'm broke.

I'm also a software engineer, I like tinkering with microcontrollers, so I built
one myself using Elixir and Nerves.
